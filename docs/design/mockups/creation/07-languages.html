2 · What the packs must say (⚑ 07 shape)

Neither test pack has a home for languages today: A keeps the 20 in a table and the common/alignment ones on races; B has an ad-hoc object. Proposed rules-set section:

languages: { common: ["common"], alignment: true | false, list: [{ id, name, blurb?, note?, source? }], extraFrom: "INT" } — with the INT table's column extraLanguages as a number (B has it; A's reads "Native + 1"). Races and classes keep their languages as ids into the list. The option that turns alignment tongues off keeps working through alignment.

Checked: given and picked clearly separated and worded; the count explains (N9); search above 12 rows (A's list is 20); 44 px rows; 375 px one column; one accent (Next); never colour alone. Not drawn: dark mode; a setting with no language list at all (the step doesn't exist; the race's languages go straight to the sheet).
