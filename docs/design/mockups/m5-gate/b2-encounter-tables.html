One list, no headings, no buttons: the row is the target. Order: tables pinned for this session, then the hit's candidates in D12's order with the likely one first (each row says why it's here), then the rest. A pinned table says "pinned" in words; the pin button itself shows only in prep (screen 4). Each row carries the table's one-line description from the pack (a new optional field, `tables[].description`; without one the row shows the die and where it applies, nothing more). No Enter roll anywhere.
