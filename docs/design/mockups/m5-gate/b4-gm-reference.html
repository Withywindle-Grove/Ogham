Setting rules · p. 38

A fallback and a stand-in for the referee's paper screen: it is not tied to what the GM is doing on another screen. Fixed panel order; the screen reopens on the panel last used. The search field never takes focus by itself (A4) and searches every panel. Each entry is the pack's text in its own words with its page. A table named in an entry opens full screen (B2's table screen) with a tap; the Tables panel is the Tables › library. Panels after the standard five come from the pack (Saints' days) or the adventure (Flood tide); their source tag says which. With more than one rules set or adventure attached, a pack switcher (pressed button = the pack shown) sits above the panels (Francis, 2026-11-01); the switcher is absent with one pack.

2 · Where the content comes from

Combat · the rules set's fight rules: initiative, surprise, morale, death and dying, pursuit — the sections the engine already reads, shown as text
Dungeons · the exploration procedures and the dungeon reference sections (darkness, doors, resting, searching, traps, wandering monsters), plus the common player actions (DG10), grouped as the pack groups them
Class abilities · every class's abilities by level, as on a character sheet's ⓘ
Equipment · the items by category with cost, weight and notes
Tables · the Tables › library (B2), with session pins
Pack and adventure panels · an optional `gmReference` list on a rules set or an adventure: panels of entries (heading, text, an optional table, page). A pack without one gets the five standard panels only

Nothing is typed into the app: every line is the pack's. Where the pack has no section for a standard panel, the panel is left out rather than shown empty ("Equipment" disappears for a setting without items). Players never see this screen; the common player actions moved here from theirs (A5).
