Messages run between the GM and a player only (Francis, 2026-11-01: no player-to-player messages). The GM sees one thread per character; a player sees one thread, with the GM. Newest first. Unread shows as a count in words, never a colour alone. Who can message: the GM, and every player with an approved character in play, writing to the GM as their character. Spectators can't. Empty: "No messages yet · New message".
