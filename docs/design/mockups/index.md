# Mockups

Mockups made to settle a ruling. From 2026-10-30 the design agent makes each new mockup as one HTML file in this folder, light and dark side by side on one page (open it in a browser); the earlier pictures below came from the old claude.ai Project. The ruling (and the spec that absorbs it) wins over the picture; `docs/design/r1/` is the R1 design of record. A picture marked `superseded` shows an option that was turned down or replaced: keep it for history, don't build from it.

Every picture in `m4b/`, `m6/` and `superseded/` has one row here, and every row has its picture (a CI check compares the two).
