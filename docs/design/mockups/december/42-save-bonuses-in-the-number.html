QuestionAnswerWhat docs/07-content-packs.md says
Can a condition carry a short word for the tile?No. Form (c) is a pack-format change.A saveBonus is a whole number, { bonus, vs?, saves? } or a list of them; vs is one free line of words. Can the pack state “a rolled 1 always fails” as data?In part. The face is data; what happens on it is words. The app reads neither today.naturals.save is { die, high: { on, text }, low: { on, text } }: low.on is the face (1) and low.text the pack’s sentence. 07 says of it: “Shown as text on save and skill prompts … never automated.” Nothing in src/ reads naturals yet.
