# The players' Scene, rows P9, P11, P12, P13: what is ruled so far

Written by the design studio on 2026-11-21 (nt-1: before a screen is drawn, everything already ruled for it is gathered). It covers rows P9 (the prompt slot at a Location), P11 (the phone), P12 (icons on the page's buttons) and P13 (every state) of `docs/plans/dec-9-the-players-scene.md`, with the app-wide standards they draw on. The newest ruling wins. Nothing here is decided: it only gathers.

Short names: `09` = `docs/09-decisions-log.md`; SM = `rulings/scene-mockup-rulings-2026-11-11.md`; S1 = `rulings/dec-mockup-rulings-2026-11-12.md`; S35 = `rulings/dec-mockup-rulings-sets3-5-2026-11-12.md`; WH = `rulings/dec-scene-whole-2026-11-14.md`; MD = `rulings/dec-midday-2026-11-14.md`; PT = `rulings/dec-pack-town-players-2026-11-14.md` (ap-10, ap-16); P2P = `rulings/scene-point-to-point-2026-11-18.md`; D5 = `rulings/dec5-flags-sitting-2026-11-20.md`; P4S = `rulings/p4-sitting-2026-11-20.md`; PPF = `rulings/p4-p2-flags-2026-11-20.md`; POP = `rulings/dec-player-popups-centred-2026-11-20.md`.
