They show how a ruling was reached; the rulings in `../rulings/` and the specs (`docs/01`–`08`) say what is true now and win over a note. Notes use the pack aliases and invented examples only; the packs' own rules and numbers stay in the private packs. Brought over from the old claude.ai Project on 2026-10-30.
