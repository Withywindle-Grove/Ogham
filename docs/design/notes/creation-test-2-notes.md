# Character creation — Francis's second test (2026-11-02, afternoon)

iPad landscape and portrait, the preview on the test project, both settings: fae-woodland first, then classic-advanced with the zine overlay. The built slices 1–7 (#255–#267) and 4b (#268). Ruled the same day in `../rulings/m5b-0c-creation-test-2-2026-11-02.md` (ct-1 … ct-10); the mockup `../mockups/creation/10-test-2-alternatives.html` (pictures in `../mockups/creation/png/`).

## What he saw (both runs)
- Score tiles clipped in both orientations; tiles staggered unevenly (the affects line wraps); "2-in-6" under STR said nothing.
- The empty ✓ square beside Kindred, Class, Alignment, spell books and kits was unclear; the entry read as one block; Pick from the entry should move on.
- Kindred-as-class classes and the zine's quick equipment were pickable with their options off; age and lifespan, combat talent (and likely thief expertise, cantrips) never appeared.
- Who they are and Secondary skills opened mid-page.
- Hit points: the prompt asked to type the die while the note said to add CON, which the app did already.
- Derived fields mostly blank ("—"); AC should show unarmoured + DEX.
- Gear forced the rolls before the kit; the money note said 3d6 without the ×10 (cf-4, pack).
- A rolled spell book's spells ran together in the panel.
- Weapon proficiencies were a typed field; specialisation (on) was nowhere.
- Affiliation, Background and Moon sign needed explainers and the die.
- "Scores, race and class can't be changed once named … built later": when? and "Kindred", not "race" (cf-7, ca-4).
- Adjust scores: the rule worked; the Undo icon and the dotted "can't lower" tiles were ambiguous.

## Rulings (summary)
Pick button on every row with Pick → Next (A) · formatted entries · Adjust scores option C (tradeable only, trade chips) · hit-points words, tile words name the thing · Derived fields only with a value · kit first · spell rows · weapon proficiencies as a list · explainers from the pack · options present when on, absent when off, with a test each.
