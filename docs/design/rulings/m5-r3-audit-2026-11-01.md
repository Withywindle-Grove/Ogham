# M5 features under R3: keep · simplify · remove (audit for Francis, 2026-11-01)

R3 (M5 gate): the app speeds up bookkeeping, record-keeping and rules lookup so players get off screens and into narration; pop-ups and reminders only where someone might miss something or must act quickly; no narration aids beyond revealing descriptions and visual aids; the players' screen is a live table view with prompts. Every feature built in M5 steps 1–12 is below. **Francis ruled 2026-11-01: yes to all four proposals that change what is built (8, 15, 20/35, 27); everything marked keep stays as built; the B items are designed next.** "Keep" needs no ruling unless he objects; the **simplify** and **remove** rows are the questions.
