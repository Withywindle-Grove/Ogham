# Creation: kindreds and classes in alphabetical order; the closed patron, finished; the M5b hold lifted (2026-11-13)

## cs-38: kindreds and classes are listed alphabetically (Francis)
His words, after importing the December packs (pack names put as the repo's aliases): "for class and race in character creation - they should be listed alphabetically. right now the elf (fae-woodland) and elf (classic-advanced) are listed seperately. it creates more confusion then necessary".

| | |
|---|---|
| The rule | On creation's Kindred step and Class step the rows are in alphabetical order by name, whatever pack each comes from. Packs are no longer the order. |
| Same name | Two entries of one name sit together, each with its "From <pack>" line (sn-1, sn-1b); between them, the campaign's stack order decides (the rules pack's first). |
| How names compare | By the name as shown, ignoring capitals; a name with a bracket sorts by its whole text ("Human" before "Human (…)"). |
| What does not move | A row that is closed to this character stays where the step puts closed rows today (its fold or its place at the end), alphabetical among its own. Other steps and the Rules browser are not changed by this ruling. |

(The lead's, on the details: the tie between same names, the comparison, and what does not move.)
