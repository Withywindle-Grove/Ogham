# M5 dungeon dry-run rulings, 2026-10-30 (Francis approved)

The design Project's paper dry run of a dungeon delve (from its `claude/dungeon-dry-run-notes.md`), approved the night of 2026-10-30. Saved by Claude Code with neutral names and invented examples only; numbers, chances and ability names stay in the private packs. The specs say what is true now; the one-line history is under 2026-10-30 in `docs/09-decisions-log.md`.

## The pause is over

M5 steps 7–12 resume with these rulings applied. Step 10 (Act…) is dropped for turn modes (DG12); day-mode activities stay in M5b.

## Starting and the clock

| # | Ruling | Where |
|---|---|---|
| DG1 | **Start expedition** asks the mode and an optional **Where?** (recent places, Choose from adventures › site → level → room, or a typed name). Choosing a dungeon place picks Dungeon mode by itself. | 05, 06 |
| DG2 | During an adventure a **compact time strip** (the pips and Next turn) shows on every GM screen, not only Explore. | 06 |
| DG3 | **Check now**: an ad-hoc wandering check at any time (from the check marker or ⋯), logged; the regular schedule carries on. | 05 |
| DG4 | Each pack's own **procedure order** (classic-advanced: check first; fae-woodland: decide actions first); a check prompts at its own step. | 05 |

## Rest and light

| # | Ruling | Where |
|---|---|---|
| DG5 | **Rest**: players get a prompt when rest is due and a **Rest this turn** button at any time; the GM's Next turn applies it (that turn counts as rest for those who chose it; checks still run). Skipping marks the pack's condition on those who didn't rest. ⓘ on the rest marker explains it in the pack's words, for GM and players. | 05, 06 |
| DG6 | **Lights**: a warning one turn before burnout ("Your torch · 1 turn left"); a burnout toast with "Light another (N left)". fae-woodland's gutter check (with the pack's option on) is one roll for the party's lights each turn. | 05 |
| DG7 | **Darkness on screen**: when a player's group has no light, their screen dims (grey for characters with dark sight, from the pack) for 3–5 seconds, then is readable again, with a "No light · Light a torch (N left)" reminder. Text stays readable (contrast rules), reduced motion is respected, and each device can turn it off. | 05, 06 |

## Splitting the party

| # | Ruling | Where |
|---|---|---|
| DG14 | **Split the party**: each party member chooses a group in a pop-up; each group has its own place, marching order, lights and statuses; **one clock** for everyone (the GM switches which group is in focus; Next turn advances all); wandering checks per group on the same schedule; **Join up** merges the groups. Separate clocks per group: parking lot. | 04, 05, 06 |
| DG15 | **Several fights** in R1 (M6): each fight is its own record (round, order, foes, HP); the GM's fight screen has a switcher; one is run at a time and the other pauses exactly where it was; each player sees only their own group's fight. M6's plan must include this. | 04, 05, 06, 08 |

## Ending

| # | Ruling | Where |
|---|---|---|
| DG16 | **End session** (GM) can happen with the party still in the dungeon; the app records where each group is and picks up there next session. | 05 |
| DG17 | **Leave the dungeon**: a quick button carrying the pack's optional rule (escape roll or safe paths). Otherwise leaving is narrative (Move… or Where?). | 05 |
| DG18 | **Escape rolls**: players enter their own rolls; the GM sees the results and narrates; the GM previews each outcome (with the chance to change it), then **Send** applies it and pops it up on that player's screen. `dungeonExit.who`: `"each"` \| `"party"` (default `"each"`) decides whether each character or the party rolls. | 05, 07 |
| DG19 | `dungeonExit` accepts either roll: `{ save }` with flat modifiers and depth (07's current example; fae-woodland's escape roll), or `{ die, rollUnder, base: { choose: [{ id, name, value }] } }` with `levelGap { compare, per, value }` and `limits { min, max }` (an invented sample rule, in a private homebrew test pack). | 07 |

## Answers to Claude Code's ⚑ (pack format names)

| # | Answer | Where |
|---|---|---|
| F1 | **Routes**: `movement.routes: [{ id, name, cost?, column?, note? }]` confirmed. A route's id is what checks' `routeType` modifiers name. Design migrates both packs from `roads` / `tracks` in the next candidates. | 07 |
| F2 | **Forced march**: either `forced.factor` (the pack's factor; round down) or `forced.add` (whole points); `forced.stack`: `"once"` \| `"add"`, default `"once"`. | 07 |
| F3 | **`alsoWhen`**: keep all four keys (`leaveRoute`, `enterRoute`, `enterTerrain`, `leaveTerrain`); only `leaveRoute` is used by a pack today. | 07 |
| F4 | **Sleep**: `camp.sleep: { difficulties: [{ id, name, roll, add? }], rows: [{ season?, fire?, bedding?, difficulty }], beddingItems, modifiers: [{ when, add, note? }], checkAbility?, note? }`, replacing `camp.bedding` and the sleep step's `difficulty`. A row's `bedding` is `"none"` \| `{ any: [ids] }` \| `{ all: [ids] }`; `beddingItems` is `[{ id, shares? }]` (a tent covers two characters). | 07 |
| F5 | **Cooking**: `camp.cooking: { ingredients?, portions: <int or dice per ingredient>, bonus?: [effects like onGoodRest], note? }`, provisional. | 07 |
| F6 | **Food**: `food`: `"fresh"` \| `"preserved"` \| `"cooked"` (portions made by cooking are `"cooked"`). | 07 |
| F7 | **Yields**: `{ item, dice }` confirmed. An activity's `bySeason` dice override `yields.dice` for that season. | 07 |
| F8 | Mounted and vehicle are speeds that go through `perDay`. | 07 |
| F9 | Eating suggests cooked first, then fresh, then preserved: confirmed. | 05 |
| F10 | A new Move… while a shortfall is owed replaces it; the log says "Course changed · <N> owed for <place> dropped". | 05 |

Also routes, forced march, `camp.sleep` with conditions, `camp.cooking`, food kinds, yields, `alsoWhen` on fae-woodland's lost check, `onlyWithOption` gates plus the three new activities (WA2–WA4 in `m5b-wilderness-2026-10-30.md`, Addendum), fae-woodland's escape roll as `dungeonExit` (`who: "each"`), the invented escape sample, and room exits linked to rooms.
