## lr-2a: the library's count line counts rules sets (the lead's)
| Id | Ruling |
|---|---|
| lr-2a | A pack row's count line counts every kind the pack holds, a rules set included ("1 rules set", after the other counts, in the line's existing form). "Nothing in it yet" only when the pack truly holds nothing. The counts stay in the pack's own words, as lr-2 rules. |
