# R1 design of record

Approved 2026-10-18. These are the source files of the "Grimoire R1 Final Review" canvas (a private claude.ai Design artifact).

- Each `*.dc.html` file is one screen: the markup shows layout and copy, the `<script>` block shows the behaviour and sample data.
- They need the canvas runtime to render, so open the canvas in claude.ai to *see* them; read these files to *build* from them.
- `canvas.json` lists the screens, their sizes and their grouping.
- All names and numbers are invented sample data. No published game text.
- Where these screens and `docs/` disagree, `docs/` wins; tell Francis so the canvas gets updated.

**Pack screens (2026-10-23):** 05's grouping by where things are carried (Worn and in hand · one group per container · Carried; armour mode's closed Gear group) replaces the mockups' grouping by kind (Treasure, Magic); kind shows as a small marker on the row. The Party stash, not in the mockups, is a folded section at the bottom of every Pack tab and a section of the GM console.
