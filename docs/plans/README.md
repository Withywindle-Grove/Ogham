# Build plans

One file per milestone step, `<milestone>-<step>.md` (for example `m5b-weather.md`), written by the design agent and read first by the builder. Each plan says what to build and in what order, links the rulings and spec sections it rests on, lists its open ⚑ items for Francis, and gives an estimate in turns. A plan doesn't make rulings: those live in `../design/rulings/` and the specs.
