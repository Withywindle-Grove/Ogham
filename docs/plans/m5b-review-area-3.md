## Build order

2. **Armour tier (G-65).** `allows()` (`src/modules/inventory/equipWarnings.ts`) reads `items[].armour.tier` as well as `armourType`: a class whose `armourAllowed.types` names either may wear the item. Test: "a class allowed 'quilted' may wear an item whose tier is 'quilted'."
3. **Magic armour.** `allows()` stops letting every `armourType: "chosen"` item through. With a base chosen, the base's type (or tier) is checked; before one is chosen, the bases the item offers (`armour.baseArmour.choose`) are checked, and the item is blocked when none of them fits. With no bases listed, `"chosen"` still passes (07). The Pack's equip check resolves the base from the setting's items: `EquipContext.item(id)` (new, optional) and `asItem(line, context)` add `chosenBase` and `baseOptions` to the item it checks. Tests: "a class allowed no armour can't wear chosen-type magic armour, base chosen or not"; "with a base chosen, the class is checked against that base".
8. **`pack:check` warns on** a `startingKits` roll without a name, a die or rows (and a row without whole `min` and `max`), which the app drops without a word; an item whose name says "(N)" or "bag / pouch / case of N" with no `bundle`; a rules set's `treasureWeights` that lacks a category of items the pack places as treasure.
