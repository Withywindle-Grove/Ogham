## Departures
- **A, the icon set (2026-11-13, builder, `dec-9a-icon-set`):** built as the row says: `Icon` takes a set name and draws it filled on the 512 grid; the table is `src/ui/iconSet.ts` (name, author with the link the set's licence file gives, CC BY 3.0), the seven `.svg` files sit unchanged in `src/ui/iconSet/` as downloaded from the set's official repository. Four small additions or narrowings, all data and logic: (1) a reader, `packIconOf(name, 'step' | 'condition')`, says what a pack's icon name draws (the set's icon, an old step symbol, or a status symbol; null for an unknown name), for pieces B and C to use; (2) a condition's `icon` does not take a set name: pf-12c names a step's `icon` and a rule's `button` only, and the status symbols stay their closed list; (3) `lost`, on the format's step list but never drawn, resolves to its letter, as it shows today; (4) the "every pack name resolves" test reads the pack-format fixtures in `scripts/fixtures/` (the private packs aren't in the repo); the expedition test fixtures are left out because one names an unknown icon on purpose. The table carries no plain name for each icon: that is the Credits' words, piece B's. Status: `docs/status/2026-11-13-dec-9a-icon-set.md`.
- **C, the checker's slice (2026-11-13, cloud builder):** `pack:check` reads a `procedure` on a place and on the rules set (`scripts/pack-procedure.mjs`). A mode's procedure keeps today's checks. Two rulings by the lead, 2026-11-13: (1) a step's `text` is the same thing as a rule's `text`, with no second shape: non-empty words, or `{ "blocks": [ … ] }` with a non-empty list of objects (rt-1; corrected the same day from "a string or a list"). Anything else is an error, a bare list included. The blocks' inner keys aren't checked here: a later piece adds one shared validator for rule-text blocks, which this check will call. (This replaces the plan's "`text` is words".) (2) A place's `encounterCheck` has no id in 07, so a step's `checkId` is matched only against the ids the format defines (a mode's checks). Status: `docs/status/2026-11-13-dec-9-c-procedure-check.md`.
- **B, "About this app" (2026-11-14, builder, `dec-9-b-about`):** built as the row says: the item above Sign out is one `MenuItem` among the account's items, so the ⋯, the phone drawer's foot and the tablet's menus all show it from one place; the sheet `AboutThisApp` shows the app's name with the build's own version ("Tome, version a1b2c3d, built 15 Jan 2026"; "Tome, version dev" on a computer), the Credits generated from the icon table, and the fonts. Departures: (1) **the fonts are all five the app bundles today** (Bitter, Alegreya Sans SC, then EB Garamond, Atkinson Hyperlegible, Caveat), not the picture's two: the picture drew the fonts after the sweep; a test ties the list to `src/ui/fonts.css`, so it shrinks to two when the sweep drops the others (ruled ab-1 by the lead, 2026-11-14: all five, as built; the shrink to two is in the sweep's plan). (2) **The line says "some are mirrored" only once an icon is mirrored** (ds-6b's words); no icon in the table is mirrored yet (the dagger isn't taken), so today it reads "Icons are shown in the app’s colours." A row gets "(mirrored)" from an optional `mirrored` on its credit; the icon table itself gains no mirror flag until the first mirrored icon is taken and `Icon` draws it flipped. (3) **Each icon's plain name** (`plain`) is added to the icon table, with the names the pictures give: Trumpet, Crystal ball, Sword, Wizard’s hat, Chest, Splash, Hourglass, Two coins. (4) **A new Dialog variant, Side** (the drawer's twin at the right, the whole screen on a phone), for the picture's full-height panel at the right; no existing variant draws it (approved by ab-1 as one part, shared with Notes, named in 06's inventory). (5) **The licence links are 44 px targets** (inline, kept whole on their line), so a row is a little taller than the picture's 40 px. (6) The item carries the `info` icon, as every menu row has its own (B11); the picture draws the rows without icons. **The menu's real order against picture 08-04:** the picture shows Setting rules, Your characters, Text size, Theme, Rules library, About this app, Sign out, each with a chevron.
