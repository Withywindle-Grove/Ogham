## Build order (each its own PR, from main)
1. **Party and self modifiers that add or set** (ex-2, ga-3): a check's or activity's `modifiers` read `ifPartyHas { class | skill }` (applies while someone in the group has it), `who: "self"` with `ifClass` (that character only), `onlyOnTerrain`, and `chance: { on: [faces] }` (sets the faces; the best for the party wins) beside `add`; the roll line names each source ("lost only on 1 · a <class> in the party"). Lost and surprise checks first. 3–4 turns. No migration.
2. **Skill lists and best-of fills** (ex-3, ga-4): an activity's `chance.skill` as a list, the best target counts and the roll line names it; a skill field's `fill: { best: ["base", { classSkill }] }` on the sheet, its breakdown naming which counted (ct3-9); one function for both. 2–3 turns. No migration.
3. **Slot bands** (ga-1, with sr-9): `encumbrance.slot.bands { equipped, stowed }` with `combine: "slowest"` in the shared speed function (bq-5), so travel, the sheet's Movement and the Pack tab agree; the Pack tab's two bars with the band that sets the speed named (sr-9). One list (`tiers`) keeps working. 4–5 turns. No migration (rules data; loads are worked out).
4. **A row's next table by terrain** (ga-2): `next: { byTerrain, default }` opens the current terrain's table, the GM can pick the other from the header; `pack:check` warns on a missing table. 2 turns. No migration. **Follow-up (fi-8, ruled 2026-11-04, `design/rulings/m5b-pack-review-area-4-2026-11-04.md`; after the gate's builds, ~1 turn):** `next: { regional: true }` opens the party's region's table (`wildEncounters.regionalTables`) or the region list when the region isn't known; `pack:check` treats a row with `next` as resolved and warns when `regional` is used with no `regionalTables`. Test: "a Regional row opens the current region's table; with no region set, the list of regions". **fi-8b:** `next.byColumn: { "<column>": { regional: true } | "<tableId>" }` branches by the column rolled (the one `encounterColumn` or the GM picked); `pack:check` warns on a key that isn't a column. Test: "a row regional in one column of four opens the region's table only when that column was rolled".
5. **Options run by hand** (ex-7): an option with `manual: true` shows "Run by hand · the app doesn't apply this yet" in set-up and Rules, its rules one tap away, the choice saved; `pack:check` lists every `manual` option. 1–2 turns. No migration.
6. **Day-food from a bundle** (G-108, ga-5): an activity's `yields` may count `units` (single days of a bundled ration, G-92's units), so foraging gives "3 days of rations" from a week's bundle item. 1–2 turns. No migration.

Tests (purpose first): "a fumbled talk lowers the sleep roll and the line says why"; "a worked cooking raises it"; "with no fumble fact in the pack, the Fumbled button isn't there"; "Didn't work makes no pot and no fact".

**PR 2, skill lists and best-of fills** (`m5b-area-2-2-skills`, ex-3, ga-4):
- **One rule for both** (`src/modules/library/skillChance.ts`): each value becomes its chance of success in whole numbers (a target `equal-or-over` on its die, x-in-N, "2-in-6", a run of faces "1-3", a percentage); the highest counts, **on a tie the first listed**; a value whose chance the notation doesn't say is passed over, never guessed. A run of faces ("1-2") counts on the skill's die, or on a d6 when the die's words name one (a class whose skills are mostly percentages may say in its `die` that one is on a d6).
- **The sheet** (`bestFill`, `fills.ts`): `"base"` is the number the fill worked out before (the rules' default, the class's same-id skill, the race's and the skill's own `fill.races` / `fill.classes`); a `{ classSkill }` is the class's `skills.byLevel` value at the character's level, written on the general skill's scale (Keen ear "1-3" on Hark's 5+ style is 4). A class skill that can't be written on that scale (not a whole face) is shown in the breakdown as "not on the same die, so not counted".
- **The activity:** of the listed skills the character has, the best counts; the line names the one rolled and adds "the better of A and B counts" when they have two or more; with one, the plain roll as before. With the sheet's fill on, the general skill already holds the class's number, so a tie goes to the general skill (listed first) and the line names it: the sheet and the roll show the same number. The GM's secret request has no character, so it reads "Roll the better of <ids>".
- **`pack:check`** names a `chance.skill` that isn't an id or a list of ids; `fill.best` isn't checked (no skills checker exists; not asked).
- **Fixture:** the Mire Stalker gains Keen ear (`EAR`), Hark `fill.best`, fen-trek a free activity Hark for prowlers, and the level fill's target gains `skills` (the class's skills fill, as in the real packs).

**PR 6, day-food from a bundle** (`m5b-area-2-6-food-units`):
