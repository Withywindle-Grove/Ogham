# 11 — Modelling gaps register

Lists the rules and data shapes from real sources that the app or the pack format can't yet express. Pack converters add rows (see the converter skill's `PLAYBOOK.md` §2). The design agent reviews the register and gives each row a release, which then appears in `08` or its parking lot. Each row describes the mechanism in neutral words: no game, book or rule names. Neutral pack IDs only.
