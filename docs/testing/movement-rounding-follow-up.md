# Manual checks: movement-rounding-follow-up

The phone's tap-for-details pop-up on a movement figure now says "(rounded down)" when the figure was rounded, like the tablet sheet.

1. [ ] On the preview, on a phone, open a character whose speed doesn't divide evenly by your setting's fight divisor (for example a speed of 20 with "In a fight" worked out as speed ÷ 3). If none has one, ask the GM to give a test character a kindred with such a speed.
2. [ ] Find the "In a fight" movement field on the sheet. It shows a whole number (6 for a speed of 20).
3. [ ] Tap it. The pop-up reads "In a fight: speed / 3 = 6 ft per round (rounded down)."
4. [ ] Tap a movement field that comes out whole (for example "Exploring", speed × 3 = 60). Its pop-up has no "(rounded down)".
5. [ ] On a tablet, open the same character's full sheet and tap **In a fight** in the Movement section. It reads the same as the phone's pop-up.
6. [ ] Start a journey with that character in the party. The day's budget is a whole number, as before.
