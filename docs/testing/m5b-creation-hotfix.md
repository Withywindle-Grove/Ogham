# Creation hotfix before the players' test (2026-11-06): weapon proficiencies shown twice, language ids, option-off weapons

On the iPad, in a campaign using the classic-advanced pack with the weapon proficiency option on:

1. Create a character, Guided. Pick a race and a class. On **Who they are**, there is no "Weapon proficiencies" box; Next goes on to the **Weapon skills** step, which still asks for the picks.
2. On the race step, open a race whose languages come from an add-on pack (an overlay language). The **Languages** heading shows names (for example "Common · Dryad"), never ids such as "zc-dryad".
3. Do the same on the class step: the class's **Languages** heading shows names.
4. With a setting whose languages step is skipped (nothing to pick), finish creation and open the sheet: the languages field shows names, not ids.
5. In a campaign with the zine compendium attached and its gunpowder option off, go to **Weapon skills**: no gunpowder or energy weapon is listed. Turn the option on in the campaign's options and start a new character: they are listed.
6. On **Gear**, a kit or given gear that names an item switched off by an option leaves that item out (it isn't put in the pack).
