# Manual checks: dec-1c-closure-words

On the preview, as a player, in a campaign whose setting has a creation method that leaves some classes out (and a kindred-class named like its kindred, if the setting has one).

1. Join with a character, pick that method, then on Class open the folded group of closed classes and use **Ask the GM to allow it** on one.
2. Finish and reach the review. The class line's warning reads "<class>: not with <method>", not "isn't open to <kindred>".
3. As the GM, open the approval card: the same words.
4. With a kindred-class named like its kindred (if any), the review's line names it once: "<Name>, level N".

No gallery pictures change.
