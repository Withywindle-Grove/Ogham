# Manual checks: m5b-nc-1-night-checks

On this pull request's preview, as the GM, in a campaign whose setting has a day mode with one wandering check marked for the day and one for the night (`onlyAt`). The walk setting doesn't mark them yet, so with it nothing changes.

1. Start an expedition in that mode; the clock is in the morning. Open ⋯ on the time strip, tap **Encounter check**. The card shows the day's check (and any with no time limit), not the night's.
2. Make camp for the group. Tap **Encounter check** again. The card shows the night's check, not the day's.
3. Tap **Next day**. The move stops for the night check first ("The night"), as before.
4. In a setting with no camp, use **Advance by…** to put the clock past 22:00, then **Encounter check**: the night's check.

No gallery pictures change.
