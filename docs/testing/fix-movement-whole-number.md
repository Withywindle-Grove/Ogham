# Manual checks: fix-movement-whole-number

Movement figures the app works out from a speed are now whole numbers, rounded down.

1. [ ] On the preview, open a character whose speed doesn't divide evenly by your setting's fight divisor (for example a speed of 125 with "In a fight" worked out as speed ÷ 3). If none has one, ask the GM to give a test character a kindred or load with such a speed.
2. [ ] On a tablet, open that character's full sheet and find the **Movement** section. "In a fight" reads **41 ft per round** (a whole number), never "41.666666666666664".
3. [ ] Tap **In a fight**. The breakdown reads "In a fight: speed / 3 = 41 ft per round (rounded down)."
4. [ ] Tap **Speed**. Any folded figures under it (running, swimming…) are whole numbers too.
5. [ ] With a speed that divides evenly (for example 30), the figures are unchanged and the breakdown has no "(rounded down)".
6. [ ] On a phone, the sheet's movement fields (the setting's layout) show the same whole numbers as the tablet.

Gallery pictures expected to change: none (no gallery specimen uses a speed that leaves a fraction).
