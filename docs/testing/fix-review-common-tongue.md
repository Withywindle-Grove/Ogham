# Manual checks: fix-review-common-tongue (F22)

On the pull request's Vercel preview (the test project), or the live app after the merge, in a fae-woodland campaign:

1. As a player, tap **Create your character**, then **Guided**. Leave the scores as they are (Intelligence 10 gives no extra language). Pick **Human**, then **Hunter**, and give a name.
2. Go through Equipment as you like. On **Human backgrounds**, pick one (don't tap Decide later). Go on to the review.
3. You should see a **Languages, given** section that reads "Woldish" (the setting's common tongue).
4. Make a second character, a **friar**, the same way, picking a background. Its **Languages, given** should list Woldish first, then the church's tongue, each once.
5. After sending, open the character's full sheet: Languages shows the same list.

Gallery pictures expected to change: none. The creation review specimens use fixed data, not this save path.
