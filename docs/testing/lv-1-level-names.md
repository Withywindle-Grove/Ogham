# Manual checks: lv-1, a spell level's words (branch ct-1-level-zero-label)

1. **The gallery.** Open the component gallery and scroll to the last section, "A spell level's words". You should see:
   - First spells with "Glimmers: pick 2". Each level-0 spell's line starts "Glimmer". The foot says "… glimmers to go".
   - First spells with the fallback: "Level 0: pick 2", lines starting "Level 0", and the foot "… level 0 spells to go".
   - A Glimmers step whose group reads "Pick 1", not "Glimmers: pick 1".
   - The Magic section with rows reading "Glimmer, …" and the tab "Spell book: 1 spell, 2 glimmers". Its fallback twin reads "Level 0, …" and "Spell book: 1 spell, 2 at level 0".
   - The unlevelled Glimmers list: every row starts "Glimmer".
   - The trait roll: "roll d3 for one lesser glimmer".
2. **Creation with a real pack.** Make a character in a class with level-0 spells.
   - If the pack names that level, First spells shows the pack's word.
   - If it doesn't, it shows "Level 0". The word "Cantrips" never appears.
   - Tap a level-0 spell: its pop-up's "Level" reads "0" (or the pack's word, such as "Glimmer"), the same as on the Magic tab.
3. **The sheet.** Open that character's full sheet, Magic section. The level-0 rows and the Spell book count use the same word as First spells.
4. **The Magic tab.** With that character prepared and in play, open the Magic tab.
   - If the pack names level 0, its heading is the pack's plural (such as "Glimmers"), and a spell's pop-up reads the single form under "Level".
   - If it doesn't, the heading is "Level 0" and the pop-up reads "0".
   - On the full sheet, the Magic section's "Spells a day" line uses the same words as the tab's headings (such as "Glimmers ●●"); a level the pack doesn't name reads "Level 1 ●●".

Gallery pictures expected to change: none of the existing ones. The new section is new pictures, for the lead.
