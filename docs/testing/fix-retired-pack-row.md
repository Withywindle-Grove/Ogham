# Manual checks: fix-retired-pack-row

A retired campaign's Setting rules no longer offers changes on its pack rows.

1. Sign in as a GM who has a retired campaign with at least one pack from their own Rules library attached (and, if you have one, a homebrew pack). Open the campaign, then Setting rules.
   You should see each pack's name, version and counts, and "Optional rules" / "What's in it" where they apply, but **no** "Update from a new file", **no** "Remove…" and **no** ⋯ button on any pack row.
2. Open a campaign that is not retired, then Setting rules.
   The same pack rows show "Update from a new file" (on your own packs), "Remove…" and the ⋯ button (on homebrew packs) as before.

Gallery pictures expected to change: none (the gallery has no retired campaign's Setting rules).
